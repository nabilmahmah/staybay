# staybay

This project aims to develop a delivery application for booking residential apartments,
enabling users to search for accommodations for rent for a specific period, and view their details.

StayBay has many great features:
1. Possibility to create an account that contains user information from name, number, password, personal photo, identity photo and date of birth (the age should be at least 18 years old)
2. View the apartments available in a clear and flexible way with an interface Simple Understanding and Use
3. Adding and browsing apartments from one account (I don't have to change the account between a renter and a tenant)
4. Extensive options for the apartments period By: Name, city, area, price, space, evaluation, presence of wifi, and presence of a swimming pool
5. Adding apartments to the list of favorites with Direct booking possibility
6. Full reservation management system through: Ensure that the reservation is not conflicted between users Enable the tenant to follow all his current reservations and even canceled with the ability to evaluate the apartment after his stay. Reservation with the possibility of accepting or rejecting the reservation
7. View the details of the apartments: the name of the apartment, the location of the apartment, the name of the owner of the apartment
8. View the personal information and the apartments of the user, in addition to the balance
9. The ability to switch between Arabic and English
10. Choose the theme that is suitable for the user's taste between Light Theme and Dark Theme
11. There is a chat for communication between the tenant and the owner of the apartment
12. Receiving notifications when the reservation status changes or receiving any message from the tenants or the owners of the apartments
13. The control panel: a web interface for the system manager that allows the acceptance and rejection of users and the addition of credit to the users Cubit has been relied upon as State Management
